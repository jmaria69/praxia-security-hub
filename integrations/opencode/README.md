# OpenCode Integration — Praxia Security Hub

OpenCode development agents connect to Praxia Security Hub using the MCP protocol or proxy variables.

## MCP Setup
```json
{
  "mcpServers": {
    "praxia": {
      "command": "/home/jmari/proyectosIA/praxia-security-hub/scripts/praxia-mcp"
    }
  }
}
```

## CLI Setup
```bash
export OPENAI_BASE_URL="http://127.0.0.1:8888/v1"
```
